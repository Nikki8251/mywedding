# 杨宇浩 & 王宁 · 婚礼筹备 App

一个给全家共用的婚礼筹备清单网站：首页封面、筹备清单（服装/采购/准备，共 84 项，可打勾、按负责人筛选）、流程手册（仪式流程/父母流程/总管职责）、宾客清单（可共同添加）。所有人打开同一个网址，看到的是同一份数据。

## 部署到 Vercel（约 5 分钟）

### 第一步：注册 Vercel（如果还没有账号）
打开 https://vercel.com/signup，用邮箱或 GitHub 账号注册，免费版足够这个项目用。

### 第二步：把代码传上去

**方法 A：不用 GitHub，最快（推荐）**

在电脑上装好 [Node.js](https://nodejs.org/)（装 LTS 版本即可），然后：

1. 解压这个项目文件夹
2. 打开终端（Mac 是"终端"App，Windows 是命令提示符/PowerShell），进入这个文件夹：
   ```
   cd 解压后的文件夹路径
   ```
3. 运行：
   ```
   npx vercel
   ```
4. 第一次运行会让你登录 Vercel（会打开浏览器授权），然后一路按回车用默认选项即可（项目名字可以直接回车用默认的，也可以自己起一个比如 `yh-wn-wedding`）
5. 等它跑完，会给你一个 `.vercel.app` 结尾的网址，这个先是"预览"链接。之后正式上线用：
   ```
   npx vercel --prod
   ```
   这一步之后给的网址就是可以长期发给家人用的正式链接。

**方法 B：用 GitHub（如果你熟悉 GitHub）**

1. 把这个文件夹传到一个新的 GitHub 仓库
2. 在 Vercel 后台点 "Add New" → "Project"，选中这个仓库导入
3. 其他保持默认，点 Deploy

### 第三步：加一个免费数据库（关键这一步，不然打勾不会互相同步）

打勾、加宾客这些数据需要存在一个真正的在线数据库里，不能只放在网页里。Vercel 自带的方式是接一个免费的 Upstash Redis：

1. 进入你这个项目在 Vercel 后台的页面
2. 点顶部的 **Storage** 标签
3. 点 **Create Database** → 选 **Upstash** → **Redis** → 选免费的 Free 档位
4. 创建好之后，点 **Connect Project**，选中这个婚礼项目，把它连接上（Vercel 会自动帮你把数据库的连接信息加到项目的环境变量里，不用手动填）
5. 回到项目的 **Deployments** 页面，找最新的一次部署，点右上角的 "..." → **Redeploy**（连上数据库之后需要重新部署一次让它生效）

做完这一步，家人打勾、加宾客的数据才会真正互相同步。

### 第四步：分享网址

把 `xxx.vercel.app` 这个网址发到家庭群里，大家用手机浏览器打开就行，还可以"添加到主屏幕"当图标用。

## 本地预览（可选）

如果你想在正式部署前先在自己电脑上看看效果：
```
npm install
npm run dev
```
然后打开 http://localhost:3000 。注意：本地运行如果没连数据库，打勾的数据只会临时存在内存里，重启就没了——这是正常的，部署到 Vercel 并连好 Upstash Redis 之后就没这个问题了。

## 项目结构说明（如果之后想自己改）

- `lib/data.js` — 清单里的固定内容（84 个筹备事项、仪式流程、父母流程、总管职责），来自你原来的 Excel
- `pages/index.js` — 页面和交互逻辑
- `pages/api/status.js`、`pages/api/guests.js` — 后端接口，负责把打勾状态和宾客名单存到数据库
- `public/cover.jpg` — 首页封面照片，想换图直接替换这个文件（保持文件名 cover.jpg）
- `styles/globals.css` — 所有样式

首页每 6 秒会自动刷新一次数据，所以家人之间的更新基本是"准实时"的，不需要手动刷新页面也能看到别人刚打的勾。
